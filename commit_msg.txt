fix(example): Wire Provider instances into static facade for debug panel

The MonetixDebugPanel accesses Monetix.gate and Monetix.rewarded through
statics, but the example app created everything via Provider without
registering those instances. This caused "Monetix not initialized" errors
when opening the debug panel.

Changes:
- Added Monetix.wire() — adopts externally-created instances into the
  static facade without creating new ones. Unlike bootstrap(), this is
  for Provider-based setups where the app owns the lifecycle.
- Added _MonetixWire helper to the example that captures Provider-resolved
  instances after the first frame and wires them into the statics.
- Added diagnostic_ad_analytics.dart to the barrel export.

Now toggling premium, ad-free breaks, and config flags in the Provider
tree propagates live to the debug panel and any code accessing statics.
